# Summarise an optional AMD reader result

Summarise an optional AMD reader result

## Usage

``` r
# S3 method for class 'amd_prediction'
summary(object, ...)
```

## Arguments

- object:

  An object returned by
  [`predict_amd()`](https://mmendoza1967.github.io/AMDconfigurations/reference/predict_amd.md).

- ...:

  Unused.

## Value

A list of proposals, conditional reliability, applicability and scores.
