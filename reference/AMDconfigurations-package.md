# AMDconfigurations: Average Membership Degree and AMD curves

`AMDconfigurations` computes Average Membership Degree (AMD) from a
soft-membership matrix and constructs AMD curves over candidate numbers
of configurations. The AMD definition is independent of the algorithm
used to estimate memberships; the current curve backend uses repeated
fuzzy c-means. The package keeps score calculation, curve construction,
interpretation and final assignment as distinct operations.
